# FXLS8961AF

The FXLS8961AF is a compact 3-axis MEMS accelerometer
designed for use in a wide range of automotive security
and convenience applications that require excellent offset
and sensitivity stability over temperature.

This smart sensor includes advanced digital features such
as the SDCD (Sensors Data Change Detection) block for inertial
event detection, auto wake sleep, 32 sample FIFO/LIFO buffer 
ensuring overall power savings.

The device supports ±2/4/8/16 g user-selectable, full-scale
measurement ranges with both I2C and SPI digital interfaces.

The FXLS8961AF is available in a 3 mm x 3 mm x 1.25 mm
12-pin QFN package with 0.65 mm pitch and wettable flanks.
The device is qualified to AEC-Q100 and operates over the
extended –40 °C to +105 °C temperature range.

For more info, please visit the device page at [https://www.st.com/en/mems-and-sensors/fxls8961af.html](https://www.st.com/en/mems-and-sensors/fxls8961af.html)
