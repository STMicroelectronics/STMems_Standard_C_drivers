# FXLS8974CF

The FXLS8974CF is a compact Low-g 3-axis accelerometer
designed for applications requiring ultra-low power
wake up on motion. This device is targeted for automotive
remote keyless entry (keyfob) motion wakeup applications.

This smart sensor includes advanced digital features such
as the SDCD (Sensors Data Change Detection) block for inertial
event detection, auto wake sleep, 32 sample FIFO/LIFO buffer 
ensuring overall power savings.

The device supports ±2/4/8/16 g user-selectable, full-scale
measurement ranges with both I2C and SPI digital interfaces.

The FXLS8974CF is available in a 2 mm x 2 mm x 0.95 mm
10-pin DFN package with 0.4 mm pitch and wettable flanks.
The device is qualified to industrial standards over the
extended –40 °C to +105 °C temperature range. The combination 
of sensor performance, system power-saving features, and extended
over-temperature-range performance makes FXLS8974CF an ideal 
accelerometer for motion sensing in the IOT.
