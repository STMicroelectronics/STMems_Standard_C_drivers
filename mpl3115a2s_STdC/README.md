# MPL3115A2S

The MPL3115A2S is an absolute pressure sensor and altimeter
with I²C interface,ideal for altitude, weather, and
industrial monitoring.

MPL3115A2S covers 20-110 kPa operating pressure range for 
broader range of applications. This part supports 20-bit
pressure (Pascals), 20-bit altitude (meters), and 12-bit
temperature; with oversampling up to 128x (1.5 Pa noise).

The pressure and temperature data is fed into a high-resolution
ADC to provide fully compensated and digitized outputs for
pressure in Pascals and temperature in °C.

The device support operating temperature range from −40 °C to
+85 °C.


For more info, please visit the device page at [https://www.st.com/en/mems-and-sensors/mpl3115a2s.html](https://www.st.com/en/mems-and-sensors/mpl3115a2s.html)
