# NMH1000

The NMH1000 is a compact, ultra-low power and low voltage
hall effect magnetic field switch. The switch is most
sensitive to a vertical field passing through the 
top-to-bottom surfaces, orthogonal to the plane.
The switch operates at low voltage, low current,
low output data rate, and is a small physical size.

This sensors supports standalone mode (no MCU needed)
where using sensor pins can be configured for threshold,
and ODR selection. The out pin indicate the change in
magnetic fields and show binary state. For more flexible
operations, sensor also support I2C mode where MCU can
configure user defined threshold and ODR over I2C.

The NMH1000 is available in a 1.4 mm x 1.4 mm x 0.85 mm
6-pin VSON package. The device operates over the
temperature range of –40 °C to +85 °C and voltage
range of 1.2V to 3.6V.

For more info, please visit the device page at [https://www.st.com/en/mems-and-sensors/nmh1000.html](https://www.st.com/en/mems-and-sensors/nmh1000.html)
